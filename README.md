# ExpenseTrack 💸

A simple expense tracker built with Python. This is my first Python project, and I'm building it to improve my programming skills through practice.

## Features

- Add expenses with amount, category, description, and date.
- View saved expenses.
- Validate user input.
- Save expenses to a CSV file.
- Load previous expenses when the program starts.

## Built With

- Python
- CSV
- Git and GitHub

## How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/muhammaduqail007/expense-tracker.git
   ```

2. Open the project folder:

   ```bash
   cd expense-tracker
   ```

3. Run the program:

   ```bash
   python main.py
   ```
